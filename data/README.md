# AstraHeal Data Directory & Provenance Policy

This directory houses raw and processed telemetry datasets utilized in the AstraHeal research platform.

## Directory Structure

- `raw/`: **IMMUTABLE RAW STORAGE**. Source files ingested from external repositories or generated by benchmark suites are stored here. Scripts are strictly prohibited from modifying or overwriting files in `raw/`.
- `processed/`: Standardized, cleaned, and feature-engineered datasets generated reproducibly by `src/telemetry/preprocess.py`.

## Data Separation
1. **Real Public Data**: Sourced from NASA PCoE battery tests. Real laboratory cycle measurements.
2. **Simulated Spacecraft Telemetry**: Generated by our internal Electrical Power System (EPS) physics-based Digital Twin (`src/digital_twin/`).
3. **Counterfactual & Diagnostic Injections**: Parameterized fault scenarios clearly labeled with injected ground-truth metadata.
